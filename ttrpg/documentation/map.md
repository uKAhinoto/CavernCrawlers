# Map of the 99 Caverns
There are Major Regions in the 99 Caverns. Below are the regions and the caverns that belong to them.

The Outland Reach is a set of unexplored caverns and the Easternmost region in The 99 Caverns. These set of caverns are located between Gateway Cavern and "The End".
